# repAI

repAI is a sustainable recycling application built with Google AI.

## The Goal

We want to make recycling more accessible and rewarding for everyone.

## Features

- **AI Object Detection** to identify recyclable items.
- **Rewards System** for recycling.
- **Cashback Integration** for sustainable purchases.
